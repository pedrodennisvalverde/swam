SWAM DESIGN V2 - SITIO ESTATICO
================================

Esta versión sigue la referencia visual aprobada:
- estilo corporativo moderno
- fondo blanco y lavanda
- morado como identidad
- hero visual
- tarjetas limpias
- portafolio destacado
- tecnologías
- proceso
- sección institucional
- CTA y footer oscuro

Tecnologías:
HTML5 + CSS3 + JavaScript.
No requiere PHP, MySQL ni base de datos.

CARPETA img:
Coloca allí el logo, fotografías del equipo y capturas de proyectos.

IMPORTANTE:
Los bloques "IMAGEN..." son marcadores temporales. Sustitúyelos por imágenes reales.
El correo del botón de contacto está en index.html y debe cambiarse por el correo real.

Para abrir:
1. Extrae el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html con Live Server o directamente en el navegador.
